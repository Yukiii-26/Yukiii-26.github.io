## 读取规则

- **这个文件只有 724 行，全读也可以接受**，但改动时仍然只读你要动的那一段。
- 改难度 / 棋盘尺寸 → 先看 `startGame`（L454）和 `build`（L409）。
- 改规则（扩散、判定、旗子）→ 看 `reveal`（L496）、`chord`（L580）、`checkWin`（L555）。
- 改外观 → 只看 **L21–268** 的 `<style>`。
- 改主题/配色 → **L24 有一行说明「`[data-theme=light]` = 与个人主页完全一致的浅色（雾蓝白）」，浅色变量在 L51 起。**

## 这个作品的特殊约定

- **零依赖单文件**，不引任何外部库，**不要加 CDN**。
- 深浅色和全站一致：`<html data-theme="light">` + `L10–19` 预加载 + `L706–722` 切换 + `serif.css`（L269）。
- 触摸设备用长按代替右键（`L626 clearPressed` 和 `L610` 一带）。
- **这个作品在 `projects/others/index.html` 里是一张卡（编号 01，`href="../minesweeper/index.html"`）**，
  主页作品区**不放它**。改动它不需要碰主页。
