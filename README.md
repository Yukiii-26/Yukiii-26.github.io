# Yukishiro 的个人主页

个人网站。**只有 `index.html` 一个文件是网站本体**

---

## 一、先在电脑上看一眼

双击 `index.html`，浏览器就会打开。现在看到的就是最终效果。

> 改完内容后，刷新浏览器（F5）就能看到新效果，不需要别的操作。

---

## 二、怎么改内容

用**记事本**、**VS Code** 或任何文本编辑器打开 `index.html`，按 `Ctrl + F` 搜索：

```
改这里
```

一共有 9 处，每处都有 `↓↓↓ 改这里 ① ↓↓↓` 和 `↑↑↑ 改这里 ① ↑↑↑` 把要改的地方夹在中间，照着改文字就行。

| 编号 | 改的是什么 |
|------|-----------|
| ① | 浏览器标签页标题、分享给别人时的卡片文字 |
| ② | 左上角导航栏里你的名字 |
| ③ | 首屏的「你好，我是谁」+ 一句话自我介绍 |
| ④ | 「关于我」正文三段 |
| ⑤ | 右侧小档案（身份 / 城市 / 正在学 / 状态） |
| ⑥ | 技能标签 |
| ⑦ | 作品卡片（一张卡片 = 一个 `<article class="card">` 块） |
| ⑧ | 邮箱和 GitHub 链接 |
| ⑨ | 页脚文字 |

**几个要注意的点：**

- 只改**夹在标记中间的中文文字**，别动 `<` `>` 尖括号和英文单词（那是代码）。
- 想加第 4 张作品卡片：把一整个 `<article class="card"> ... </article>` 复制一份粘在后面。
- 想换主题色：搜索 `--accent:#2563eb`，把 `#2563eb` 换成别的色号（比如绿色 `#16a34a`、紫色 `#7c3aed`）。
- ⚠️ **一定要存成 UTF-8 编码**，否则中文会变乱码。VS Code 右下角选 `UTF-8`；记事本另存为时把编码选成 `UTF-8`。

## 三、上线（10 分钟，纯点鼠标）

### 第 1 步：建一个仓库

1. 打开 <https://github.com/new>
2. **Repository name** 填（必须**一字不差**，这是关键）：

   ```
   Yukiii-26.github.io
   ```

3. 下面选 **Public**（必须是公开，私有仓库的 Pages 要付费）
4. 不要勾 "Add a README file"
5. 点绿色的 **Create repository**

> 仓库名之所以这么起，是因为 GitHub 有规矩：仓库名叫 `<你的用户名>.github.io` 时，
> 它会自动把里面的网站发布到 `https://<你的用户名>.github.io`，不需要任何配置。

### 第 2 步：上传文件

1. 新仓库页面中间有一行小字 **uploading an existing file**，点它
   （找不到就直接打开 `https://github.com/Yukiii-26/Yukiii-26.github.io/upload/main`）
2. 把 `index.html` 和 `README.md` **拖进**页面中间的虚线框里
3. 页面下方点绿色的 **Commit changes**

### 第 3 步：确认发布开关

1. 进仓库的 **Settings**（顶部一排标签里的最后一个）
2. 左侧栏点 **Pages**
3. **Source** 那里应该是 `Deploy from a branch`，Branch 选 **main**、目录 **/ (root)**，然后点 **Save**
   （仓库名符合规则时通常已经自动配好了，看到 "Your site is live at ..." 就说明没问题）

### 第 4 步：打开你的网站

浏览器访问：

```
https://yukiii-26.github.io
```

**第一次可能要等 1～3 分钟**，页面刚建好时刷出来 404 是正常的，等一下再刷新。

## 四、以后想改内容怎么办

- **不改文件名、只改文字**：直接在 GitHub 网页上打开 `index.html`，点右上角铅笔图标 ✏️ 改，改完 Commit。等 1 分钟网站就更新了。
- **本机改完再传**：改好 `index.html` → 回到仓库 → `Add file` → `Upload files` → 拖进去覆盖 → Commit。

## 五、遇到问题

| 现象 | 原因和解决办法 |
|------|----------------|
| 打开是 404 | 刚建好要等 1～3 分钟；或仓库名打错了、仓库不是 Public |
| 页面是纯白，没样式 | `index.html` 没传成功，或文件名被系统改成了 `index.txt`。确认文件名正好是 `index.html` |
| 中文变问号/乱码 | 存文件时编码不是 UTF-8，重新另存为 UTF-8 再上传 |
| 改了 GitHub 上的文件但网页没变 | 等 1～2 分钟，然后按 `Ctrl + F5` 强制刷新（浏览器缓存） |
| 想加图片 | 在仓库里建个 `assets` 文件夹放图片，然后 HTML 里写 `<img src="assets/照片.jpg" alt="说明">`；先用 `https://yukiii-26.github.io/assets/照片.jpg` 试能不能打开 |
| 国内打开很慢 | GitHub Pages 在国内时快时慢，属于正常。以后可以换 Cloudflare Pages（同样免费、同样不用域名），需要时我帮你迁 |

## 六、关于域名

**你不需要买域名。** `yukiii-26.github.io` 就是你的正式网址，能正常分享、能被搜索引擎收录。

只有这几种情况才值得花钱买个 `.com`：

- 想让网址短一点、好看一点（比如 `yukishiro.com`）
- 想用来接商业项目、印在名片上

价格大约 60～90 元/年。**什么时候想买了再告诉我**，我把绑定流程一步步带你走，顺便帮你想名字。
