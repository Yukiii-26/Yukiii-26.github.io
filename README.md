## 特点

- **单文件、零依赖** —— 不加载任何外部字体或第三方库，国内访问也不用额外等待（背景图是本仓库自己的文件）
- **黄昏背景图** —— 首屏铺满一张雨夜街景插画，往下滚动的内容区自动压上深色面板，字始终看得清
- **深色主题** —— 目前只有深色（亮色版在照片上看不清，先隐藏了；样式还留着，想恢复随时能开回来）
- **自适应手机** —— 小屏幕上导航收成折叠菜单，作品列表从「编号行」改成上下排列，背景换成竖构图的另一张图
- **其他单独项目** —— 作品区下面单独留了一块，专门放「代码主要不在本站」的项目。**目前内容已清空、只保留栏目位置**，加新项目时用 `index.html` 里的 `<template id="tpl-featured-card">` 结构
- **全站同一套外观** —— 作品页（《没有人举手》、便利店、地图、扫雷、山谷）和彩蛋页、模板页都换成了同一套：深色 + 天蓝 + 圆弧角 + 同一张背景图，点进去不会像跳到了另一个网站
- **关掉 JS 也不会白屏** —— 进场动画只在 JavaScript 可用时才启用

## 《没有人举手》网页体验版

作品区第一张卡片（`projects/schoolscape/index.html`）是**第一章「后排的空位」的体验版**：约 5 分钟，从一间教室的空座位开始，问出一些没人愿意提的事。单文件、零依赖、无外部请求，手机和电脑都能玩，进度自动保存在浏览器里。

- **为什么只有第一章**：完整故事（七份证词、档案室、天台上的选择、两个结局）后面还在做，暂时没有公开；网页版先放第一章，让人不用下载就能看看。
- **后面章节没有删**：场景、对话、谜题、结局全都还在 `index.html` 里，只是被一个开关挡着 —— 在 `preview/schoolscape2/src/00-core.js` 里把 `var DEMO = true;` 改成 `false`，再跑 `node preview/schoolscape2/build.js`，网页版就把全部章节都放出来（我们自己留的开关，页面上没有入口）。

- **操作**：`WASD` / 方向键移动，`E` / 空格互动和继续，`Tab` 证词本，`Esc` 暂停，`M` 声音，`F` 全屏。手机用画面下方的方向键和按钮。
- **不知道下一步做什么？** 画面**左上角一直显示「目标：…」**（和证词本里那行是同一句），跟着它走就行。把教室里能问的都问完，目标会变成「走出教室」，走到门口就会看到「体验版就到这里」。
- **内容提示**：涉及校园霸凌与学生死亡，不描写具体方式与细节；开场有提示，结尾有现实求助信息。
- **想改台词**：搜 `TALK`（人物对话）、`NOTES`（线索笔记）、`TESTIMONY`（七份证词）、`endingLines`（结局文本）。
- **⚠️ 改之前先看清楚走哪条路**：
  - **只是临时试试**：直接改 `projects/schoolscape/index.html`，保存后双击预览就生效，不用构建。但这份文件是**构建产物**，下次构建会被覆盖，所以试完记得把改动回写到源码里。
  - **正式改**：源码分片在 `preview/schoolscape2/src/`（`shell.html` + `00-core.js` / `10-art.js` / `20-scenes.js` / `30-story-*.js` / `40-engine.js` / `50-ui.js`，**这个目录不上传**）。改完跑一句 `node preview/schoolscape2/build.js`，它会拼成 `projects/schoolscape/index.html` 并顺手做语法检查。
  - 构建时会**自动剥掉源码里的所有 JS 注释**（防止玩家看源代码读到设计笔记），所以注释只写在 `preview/schoolscape2/src/` 里，不要指望在交付文件里看到。
- **想改场景**：搜 `registerScene`，每个场景的地图、家具、交互物、人物和出口都在那里。

## 纯属搞怪：SCI-POOT 3000 放屁扩散模拟器

作品区第 4 张卡片（`projects/fartsim/index.html`）本来是本机「零碎任务」里做着玩的一个**搞怪页面**，2026-10-25 原样搬进了站里。

- **它只是为了抽象搞笑**：把一个「肠道气体边界层扩散观测平台」演得很像回事——拖三根滑块调排气功率 / 憋气时长 / 风速风向，点「执行排放」，看浓度云团在观测场上扩散开，峰值、影响半径、波及人数一路往上跳。
- **不是真科学**：模型是简化高斯气团 + 平流，参数是「目测标定」的，所有读数都不可用于任何真实安全或职业卫生评估，也不针对任何人或场景。页面上（顶部的「纯属搞怪 · JUST FOR FUN」标记、左下角说明）都写清楚了。
- 技术上：单文件、零依赖、无外部请求。画面是 Canvas 画的，声音（排气音、警报）是 WebAudio 现场合成的，没有音频文件。手机竖屏会把控制面板排到观测区下面。

## 怎么改内容

用**记事本**、**VS Code** 或任何文本编辑器打开 `index.html`，按 `Ctrl + F` 搜索：

```
改这里
```

一共 **11 处**，每处都被 `↓↓↓ 改这里 ① ↓↓↓` 和 `↑↑↑ 改这里 ① ↑↑↑` 夹在中间。

| 编号 | 改的是什么 |
|------|-----------|
| ① | 浏览器标签页标题、分享给别人时的卡片文字 |
| ② | 左上角导航栏里你的名字 |
| ③ | 首屏的「你好，我是谁」+ 一句话自我介绍 |
| ④ | 「关于我」正文三段 |
| ⑤ | 右侧小档案（身份 / 城市 / 正在学 / 状态） |
| ⑥ | 技能标签 |
| ⑦ | 作品列表（一个项目 = 一个 `<article class="card">` 块，复制一块就多一项） |
| ⑧ | 邮箱和 GitHub 链接 |
| ⑨ | 页脚文字 |
| ⑩ | 头像照片 |
| ⑪ | **其他单独项目**：目前是空的占位区（只有标题与一句占位文字）；加项目时复制 `<template id="tpl-featured-card">` 里的结构到「新项目写在这里」下面 |

**要注意的点：**

- 只改**夹在标记中间的中文文字**，别动 `<` `>` 尖括号和英文单词（那是代码）。
- ⚠️ **邮箱要改两处**：写法是 `<a href="mailto:你的邮箱">✉ 你的邮箱</a>`，**引号里和箭头后面是两个地方，必须都改**。只改后面显示的那个，别人点按钮时发给的还是老地址。
- ⚠️ **一定要存成 UTF-8 编码**，否则中文会变乱码。VS Code 右下角选 `UTF-8`；记事本另存为时把编码选成 `UTF-8`。
- 🥚 **主页藏了个彩蛋**：在主页上依次敲 `W` `W` `S` `S` `A` `D` `A` `D` `B` `A`（就是「上上下下左右左右 BA」的键盘版），会跳到 `egg/` 那一页。
  想换按键或跳转目标：在 `index.html` 里搜 `彩蛋`，改 `CODE` 和 `EGG_URL` 两行即可。
  另外打开开发者工具（F12）的**控制台**里会看到一条提示，那是留给爱翻控制台的人的唯一线索（不需要就删掉那几行 `console.log`）。

## 想换主题色

`index.html` 里搜 `:root`，会看到**两块**：上面一块是深色（现在唯一生效的），下面一块 `:root[data-theme="light"]` 是亮色（暂时隐藏，留着备用）。整套颜色是从背景图上取的：夜空深蓝打底，天蓝做强调色。

| 变量 | 作用 | 深色（当前） / 亮色（隐藏中） |
|------|------|-------------------|
| `--accent` | 强调色（小标签、编号、主按钮、悬停） | `#6ec1f2` / `#1d6fa5` |
| `--accent-hi` | 悬停时的更亮一档 | `#9ad6ff` / `#2a86c2` |
| `--accent-ink` | 压在强调色底上的字色 | `#06121e` / `#ffffff` |
| `--paper` | 页面兜底底色 | `#0b1220` / `#f6f1e8` |
| `--surface` | 卡片 / 标签的半透明底色 | `rgba(18,27,42,.6)` / `rgba(255,255,255,.76)` |
| `--ink` | 标题与正文颜色 | `#f4efe8` / `#1a1510` |
| `--muted` | 次要文字 | `#bcb5ab` / `#5f574c` |
| `--line` | 分割线 | `rgba(255,255,255,.14)` / `rgba(26,21,16,.14)` |

换完颜色记得看一眼对比度：正文与背景至少要 **4.5:1**，不然在暗处或阳光下会看不清。

### 想恢复「深色 / 浅色」切换按钮

浅色版现在只是**藏起来**了，代码都还在，恢复要改两处：

1. `index.html` 搜 `主题切换暂时下线`，把 `<button class="theme-toggle">` 那段注释去掉
2. 搜 `document.documentElement.setAttribute('data-theme', 'dark')`，把这行换成
   `saved || 'dark'`（并在上面恢复读取 `localStorage.getItem('theme')`），
   再把 `<script>` 里那段被注释掉的点击事件放回来

> 恢复前建议先重新调一下亮色版的可读性 —— 当初下线就是因为灰白的图压在文字后面看不清。

## 怎么加一个新作品（项目）

作品区每一行（一个 `<article class="card">`）就是一个项目。加项目分两步：**放文件** + **改链接**。

### 一、文件怎么摆

一个项目 = 一个文件夹，放在仓库根目录的 `projects/` 下面：

```
Yukiii-26.github.io/
├── index.html          ← 主页
├── avatar.jpg
└── projects/           ← 新建这个文件夹，专门放作品
    └── snake/          ← 一个项目一个文件夹
        ├── index.html  ← 必须有！文件名正好是这个（全小写）
        ├── style.css
        └── game.js
```

放好之后，这个项目的网址就是：

```
https://yukiii-26.github.io/projects/snake/
```

浏览器里输入上面这个目录地址就能打开（GitHub 会自动加载里面的 `index.html`）。
但**在网页里写链接时，要写到 `index.html` 为止，别只写到文件夹** —— 原因见下面「卡片上怎么写链接」。

**两种做法，按项目类型选：**

| 项目类型 | 怎么做 |
|---------|--------|
| 本身就是个能玩的网页（小游戏、小工具） | 直接把游戏放成 `projects/游戏名/index.html`，主页卡片直接链过去。**最省事** |
| 需要配文字说明、截图 | 复制 `projects/template/` 一份，改名成 `projects/你的项目名/`，在里面改内容当详情页；能玩的东西放同级的 `play/` 文件夹里，详情页的「在线试玩」按钮已经指向 `./play/index.html` |

> `projects/template/` 里那个页面是给你当模板用的，做好自己的项目后可以删掉它。
> 模板里也有自己的「改这里」标记（7 处），搜法一样。

### 二、卡片上怎么写链接

在 `index.html` 里搜「改这里 ⑦」，把那张卡片的 `href="#"` 换掉：

| 情况 | 写法 |
|------|------|
| 项目在本仓库（推荐） | `href="projects/snake/index.html"` |
| 项目在另一个仓库，想让人直接玩 | `href="https://yukiii-26.github.io/仓库名/"`（那个仓库也要开 Pages。跨到别的网站，目录形式没问题） |
| 只想让人看代码 | `href="https://github.com/Yukiii-26/仓库名"` |

> ⚠️ **为什么本仓库的链接要写到 `index.html` 为止？**
> 线上会自动打开文件夹里的 `index.html`，所以 `href="projects/snake/"` 在线上的确能用。
> **但你在电脑上双击 `index.html` 预览时不行** —— 浏览器会跳到一个光秃秃的文件列表页，
> 你就没法在上传前先自己检查了。写全文件名，两种情况下表现一致。

### 二·五、卡片上的预览缩略图

每张卡片左边那张图放在 `assets/` 里，命名 `thumb-<项目名>.jpg`，**统一 16:10（800×500）**，
一张 40 KB 左右，四张加起来还不到 200 KB。换图只要替换同名文件，HTML 不用动：

```html
<div class="shot"><img src="assets/thumb-snake.jpg" alt="一句话描述画面" width="800" height="500" loading="lazy" decoding="async"></div>
```

- `alt` 写一句人话，搜索引擎和读屏软件读的是它，别留空
- `loading="lazy"` 让图片滚到附近才下载，首屏更快
- 想重新截图：用浏览器打开作品页，按 `F12` → `Ctrl + Shift + P` → 输入 `screenshot` 选
  「Capture screenshot」，或者直接截屏后按 16:10 裁切

### 三、怎么上传

**方法一：纯网页（最简单）**

1. 打开 <https://github.com/Yukiii-26/Yukiii-26.github.io>
2. 点 `Add file` → `Upload files`
3. 把整个 `snake` 文件夹拖进虚线框里（GitHub 会保留里面的目录结构）
4. 点 `Commit changes`

> 如果拖文件夹不灵，改用这个笨办法：
> `Add file` → `Create new file`，文件名那一栏输入 `projects/snake/index.html`
> —— **打斜杠会自动建文件夹** —— 把内容粘进去，Commit。
> 剩下的小文件再逐个拖到 `projects/snake/` 里。

**方法二：装 Git 之后（以后更省事）**

```bash
git clone https://github.com/Yukiii-26/Yukiii-26.github.io.git
# 把你的项目文件夹拷进 projects/ 目录
cd Yukiii-26.github.io
git add .
git commit -m "add snake"
git push
```

### 四、最容易踩的四个坑

| 坑 | 说明 |
|----|------|
| **大小写** | GitHub 的服务器区分大小写。你 Windows 上写 `Game.js` 能跑，传上去引用就是 404。**文件名统一小写**最省事 |
| **中文文件名** | 能用，但网址会变成 `/projects/%E6%B8%B8%E6%88%8F/` 一长串，难看也容易出错。用英文小写 |
| **路径写法** | 项目内部的 css / js / 图片要用**相对路径**：`./game.js` 行，`/game.js` 不行（那是指网站根目录） |
| **只能放静态文件** | GitHub Pages 只是把文件发给你，**跑不了后端**。纯 HTML/CSS/JS 的小游戏没问题；需要 Node、Python 服务或数据库的跑不了 |

### 五、传完怎么确认

先直接打开这个网址试：

```
https://yukiii-26.github.io/projects/snake/
```

打不开就按顺序查：文件夹名大小写对不对 → 里面有没有 `index.html` → 是不是刚提交、再等 1～2 分钟 → 按 `Ctrl + F5` 强刷。

> 附：实测这个站点是「**原样发文件**」，不会对你的 HTML / JS 做任何加工。

### 隐藏 / 恢复一个作品

想暂时不展示某个作品，**不用删文件** —— 在 `index.html` 里搜「改这里 ⑦」，把那张 `<article class="card"> … </article>` 整块用 `<!--` 和 `-->` 包起来：

```html
<!--
<article class="card">
  ……
</article>
-->
```

这样卡片就从页面上消失了，`projects/作品名/` 里的文件还在，网址也仍然能直接打开（只是没人链过去）。

**现在有两张卡片是这么隐藏的**（注释里原样保留着那张卡片，想恢复把开头 `<!--` 和结尾 `-->` 删掉即可）：

- **岁月山谷（`projects/valley/`）**：搜「04 号「岁月山谷」」。恢复时注意编号不要和上面的 01–03 撞车。

> 想让「隐藏」更彻底（连网址也打不开、搜索引擎也不收），得把整个 `projects/作品名/` 文件夹删掉，或者在那个页面的 `<head>` 里加一行

## 遇到问题

| 现象 | 原因和解决办法 |
|------|----------------|
| 打开是 404 | 刚建好要等 1～3 分钟；或仓库名打错了、仓库不是 Public |
| 页面是纯白，没样式 | `index.html` 没传成功，或文件名被系统改成了 `index.txt`。确认文件名正好是 `index.html` |
| 中文变问号 / 乱码 | 存文件时编码不是 UTF-8，重新另存为 UTF-8 再上传 |
| 改了 GitHub 上的文件但网页没变 | 等 1～2 分钟，然后按 `Ctrl + F5` 强制刷新（浏览器缓存） |
| 头像不显示 | `avatar.jpg` 必须和 `index.html` 在同一层目录，文件名大小写要一致 |
| 想加图片 | 在仓库里建个 `assets` 文件夹放图片，HTML 里写 `<img src="assets/照片.jpg" alt="说明">` |
| 国内打开很慢 | GitHub Pages 在国内时快时慢，属于正常现象 |
